## 1. 项目概述

### 1.1 项目背景

孩子进入初中后，作业量增加，老师通过QQ群发布作业和通知，信息碎片化严重。家长需要一款工具来管理孩子的作业、通知、习惯养成和日常计划，帮助家庭高效协作，陪伴孩子成长。

### 1.2 项目名称

| 属性     | 值           |
| -------- | ------------ |
| 中文名   | 成长搭档     |
| 英文名   | Grow Partner |
| 项目代号 | grow-partner |

### 1.3 项目目标

| #    | 目标             | 成功指标                           |
| ---- | ---------------- | ---------------------------------- |
| 1    | 作业信息集中管理 | 家长每天使用系统登记作业，减少遗漏 |
| 2    | 通知不遗漏       | 重要通知自动提醒，按时完成准备     |
| 3    | 习惯持续养成     | 连续打卡天数≥21天的习惯达标率      |
| 4    | 计划有效执行     | 日计划完成率≥80%                   |
| 5    | AI提效           | 图片识别作业录入时间<10秒/条       |

### 1.4 目标用户

| 用户类型         | 描述                                          | 使用频率  |
| ---------------- | --------------------------------------------- | --------- |
| 家长（主要用户） | 孩子的父母，创建/加入家庭，日常录入和管理信息 | 每天      |
| 孩子             | 可查看作业、打卡习惯                          | 每周1-2次 |
| 其他家庭成员     | 爷爷奶奶等，辅助看护                          | 偶尔      |

### 1.5 平台选择

**微信小程序**（唯一平台）

- 兼容iOS和鸿蒙系统
- 无需安装，即用即走
- 微信 OpenID 身份识别，无需额外账号密码
- 支持订阅消息推送
- 云开发降低后端成本

## 3. 家庭管理

### 3.1 创建家庭

**触发条件**：新用户注册后选择「创建家庭」

**必填信息**：

| 字段       | 类型 | 必填 | 说明                  |
| ---------- | ---- | :--: | --------------------- |
| 小孩姓名   | 文本 |  ✅   | 真实姓名              |
| 小孩昵称   | 文本 |  ❌   | 日常称呼              |
| 生日       | 日期 |  ✅   | 用于年龄展示          |
| 学段       | 单选 |  ✅   | 幼儿园/小学/初中/高中 |
| 年级       | 单选 |  ✅   | 根据学段动态变化      |
| 班级名称   | 文本 |  ❌   | 如"初一(3)班"         |
| 与孩子关系 | 单选 |  ✅   | 默认为创建者身份      |

**年级动态选项**：

| 学段   | 年级选项                                 |
| ------ | ---------------------------------------- |
| 幼儿园 | 小班、中班、大班                         |
| 小学   | 1年级、2年级、3年级、4年级、5年级、6年级 |
| 初中   | 1年级、2年级、3年级                      |
| 高中   | 1年级、2年级、3年级                      |

### 3.2 加入家庭

**触发条件**：新用户注册后选择「加入家庭」

**流程**：

```
输入家庭邀请码
    ↓
搜索匹配家庭
    ↓
显示最小家庭信息（孩子姓名/昵称/班级）
    ↓
选择与孩子关系
    ↓
提交申请
    ↓
创建者收到申请通知（小程序内通知 + 订阅消息）
    ↓
创建者批准/拒绝
    ↓
批准后自动加入家庭
```

### 3.4 家庭成员管理

**功能**：
- 查看成员列表（头像、昵称、关系、角色、加入时间）
- 创建者可移除成员
- 创建者可转让创建者身份
- 成员可主动退出家庭

### 3.5 学期管理

**学期计算规则**：

| 月份范围         | 学期     | 示例               |
| ---------------- | -------- | ------------------ |
| 2月1日 - 7月31日 | `YYYY上` | 2026年3月 → 2026上 |
| 8月1日 - 1月31日 | `YYYY下` | 2026年9月 → 2026下 |

**切换规则**：
- 创建者在设置中手动切换当前学期
- 切换后所有业务数据（作业/通知/习惯/计划）按新学期过滤
- 旧学期数据隐藏但保留
- 新增数据自动使用当前学期

## 4. 作业管理模块

### 4.1 功能概述

家长记录老师布置的各科作业，支持筛选、搜索、标记完成，帮助孩子明确每日任务。

### 4.2 页面结构

```
Tab1: 作业
├── 作业列表页
│   ├── 学期切换器（左右箭头，切换上/下学期）
│   ├── 科目标签栏（横向滚动，点选筛选）
│   ├── 状态筛选（全部/未完成/已完成）
│   ├── 搜索框（按主题模糊搜索）
│   └── 作业卡片列表
├── 新增作业页
├── 编辑作业页
└── 作业详情页
```

### 4.3 作业列表页

#### 4.3.1 顶部筛选区

```
┌────────────────────────────────────────────────┐
│  ← 2026下 →                                    │ ← 学期切换
├────────────────────────────────────────────────┤
│ [全部][语文][数学][英语][物理][化学][生物]...    │ ← 科目标签横向滚动
├────────────────────────────────────────────────┤

└────────────────────────────────────────────────┘
```

**交互规则**：

| 元素     | 行为                                     |
| -------- | ---------------------------------------- |
| 学期切换 | 左右箭头切换相邻学期，当前学期默认       |
| 科目标签 | 单选，点击切换，支持左右滑动查看所有科目 |

### 5.5 自动智能提醒

**手动提醒**：
- 用户手动设置提醒时间
- 到达提醒时间前按设置的提前量推送订阅消息

**AI自动智能提醒**：
- 录入通知时，AI自动解析内容中的时间关键词
- 自动提取日期时间信息
- 自动填充提醒时间字段（用户可修改确认）
- 支持识别的时间类型：

| 类型     | 示例          | AI输出           |
| -------- | ------------- | ---------------- |
| 具体日期 | "9月8日"      | 2026-09-08       |

### 12.2 阶段规划

| 阶段    | 内容                         | 预计时间 | 完成标准                  |
| ------- | ---------------------------- | -------- | ------------------------- |
| Phase 0 | 基础架构：登录、家庭、数据库 | 3-5天    | 可注册登录，创建/加入家庭 |

| Phase 4 | 打磨优化                     | 持续     | 体验优化+Bug修复          |

### 12.3 对比评估标准

| 维度       | 权重 | 评分标准                   |
| ---------- | :--: | -------------------------- |
| 功能完整度 | 30%  | 需求基线功能实现数量与质量 |

| UI/UX体验  | 20%  | 界面美观、交互流畅         |
| 稳定性     | 15%  | 无严重Bug、边界处理        |
