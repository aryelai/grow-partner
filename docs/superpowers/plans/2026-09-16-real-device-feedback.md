# 1.0.4 真机反馈整改计划

## 目标与边界

落实底栏图文放大、紧凑更多图标、作业导入成功返回、月历筛选、科目排序与按需删除、课程表独立名称及保存说明。保留游客浏览、五入口、现有家庭权限和数据。不会在生产环境创建测试作业、修改家庭科目或更换模型，不承诺未经实测的手写准确率。

## 调研与方案

| 需求 | 已检查能力 | 选择 |
| --- | --- | --- |
| 底栏字号 | 现有原生 tabBar、微信官方 API 声明、自定义底栏机制 | 原生样式 API 不支持字号配置，采用微信自定义 tabBar，沿用路由与现有 PNG；不引入依赖 |
| 月历 | 项目日期工具、微信 picker、官方 WeUI、Vant Calendar | 当前无组件库，单日筛选采用最小月历组件，复用 UTC 日期计算；提供前后换月、选日、回到今天与关闭 |
| 科目排序 | subjects 数组与 order 已存在 | 上移/下移调用服务端相邻移动；不改变历史记录，复用设置权限 |
| 课程名 | 服务端和客户端允许任意非空名称 | 陌生名称为正常自定义课程，不等同识别不确定；不自动加入作业科目 |
| 手写识别 | 原图上传、高精度视觉参数、逐字转写提示均已存在 | 不盲目叠加提示或更换模型；优先确保原图和裁剪入口，实测对照另行进行 |

微信开发者文档页面当前无法由网页读取工具打开，已读取官方 api-typings 作为接口证据；WeUI、Vant 官方仓库用于比较，无代码复制、安装或新增第三方许可证义务。

## 执行顺序与文件

1. 在 tests 中添加失败回归：全部成功返回、部分失败保留、未选草稿确认、科目相邻移动及权限、陌生课程名、月历闰年/跨年和底栏切换失败。
2. 修改 homework-import 保存流程，成功后设定列表日期并返回作业页，保护未选草稿；失败不离开。
3. 调整 app.wxss 和两列表 WXML 的三点图标；新增 custom-tab-bar 及五页选中态同步、尾部安全区留白。
4. 新增月历计算工具和组件，接入 homework-list，保留日期箭头；草稿日期编辑仍使用原生日期选择器。
5. 修改 settings 云函数和 subject-settings 页面：权限、操作锁、相邻移动；删除仅在修改面板显示且维持默认科目限制。
6. 调整 timetable 草稿客户端、服务端与页面文案；保留覆盖确认和版本冲突保护。
7. 运行项目完整测试、静态校验、补丁检查；官方开发者工具编译并核对关键页面。最后生成新真机二维码。

## 风险与回滚

- 自定义底栏必须正确处理五页选中态、切换失败、底部安全区和遮挡；可恢复 app.json 原生底栏并移除页面同步与留白。
- 部分保存或未选草稿不得因自动返回丢失；失败仍留原页，未选项需要明确确认。
- 排序是当前家庭配置写入，测试使用隔离替身；本轮不运行真实排序或删除。
- 新服务端行为未部署前不能称生产可用；部署匹配代码沿用既有授权与备份回读规则，不修改密钥、权限或隐私配置。
- iOS 真机由用户扫码验证，Android 真机仍待提供设备，不能以模拟器代替。
