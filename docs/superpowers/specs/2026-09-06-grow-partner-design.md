# 成长搭档微信小程序设计说明

## 目标与范围

按照 `docs/START.md` 和 `docs/成长搭档PRD.md` 构建零第三方 UI 框架、零业务 npm 依赖的原生微信小程序。交付范围覆盖登录与家庭协作、作业、通知、习惯、计划、设置和 AI/提醒占位能力，并以家庭和当前学期为数据边界。

## 固定约束

- 前端仅使用 WXML、WXSS、JavaScript 和微信小程序原生 API。
- 后端使用微信云函数、云数据库和云存储。
- 页面统一包含 `.wxml`、`.wxss`、`.js`、`.json` 四个文件。
- 所有云函数按 `event.action` 分发，返回 `{ success, data, message }`。
- 业务查询必须从服务端登录态解析 `openid` 和 `familyId`，不得信任前端传入的身份字段。
- 外部输入在云函数和页面边界同时校验；写操作按角色和资源所有权授权。
- 日期传输使用 ISO 8601 字符串，云数据库持久化为 `Date`；展示时由前端格式化。
- AI Key 不从前端读取、不返回明文，也不在基础版中落库；AI 能力仅交付安全占位。

## 架构

`miniprogram` 负责页面状态、表单校验、媒体选择与云函数调用。`miniprogram/utils` 提供枚举、日期、输入校验、请求封装和登录态路由，页面不直接拼装通用协议。

`cloudfunctions` 按领域拆分为 `login`、`family`、`homework`、`notice`、`habit`、`plan`、`settings`、`ai` 和 `reminder`。每个云函数是独立部署单元，因此只在其目录内保留必要的鉴权、校验和响应辅助函数，避免依赖部署目录之外的模块。

## 身份、权限与数据隔离

云函数通过 `cloud.getWXContext()` 获取 `OPENID`。除首次注册和搜索家庭外，所有 action 必须先查询 `users`；业务资源的 `familyId` 必须与当前用户的 `familyId` 一致。创建者可以管理成员和所有家庭资源；普通成员只能删除自己创建的作业；孩子只允许查看、作业状态切换、计划执行和习惯打卡。

加入家庭审批需要持久状态，而两份需求文档没有可承载审批状态的字段。为满足 Phase 0 验收，补充支撑集合 `family_join_requests`，字段为 `_id`、`familyId`、`applicantOpenid`、`relation`、`status`、`createdAt`、`reviewedAt`、`reviewedBy`。`families.inviteCode` 由服务端生成并建立唯一索引，查询限流且加入申请需要创建者审批。

## 数据与查询

- `homework`、`notices` 直接使用 `semester` 过滤。
- `plans` 使用 `date`、`weekRange` 或 `monthRange` 计算视图范围，写入时同时保存当前学期 `semester`，解决“计划按学期隐藏”与原表缺少字段的冲突。
- `habits` 写入当前学期 `semester`，`habit_checkins` 继承所属习惯的学期；这保证学期切换规则可执行。
- 列表默认每页 20 条，最大 50 条；搜索文本先做长度限制和正则转义。
- 作业排序在数据库粗排后由服务端执行稳定业务排序：完成状态、有效截止时间、重要状态、创建时间。

## 页面与交互

五个 Tab 分别为作业、通知、习惯、计划和设置。登录态恢复完成后，根据用户是否已注册、是否已加入家庭跳转到登录/家庭选择/作业列表。账号以云函数上下文中的 OpenID 作为唯一身份，家庭创建者通过邀请码邀请成员。表单页支持保存中状态和重复提交保护；错误通过统一提示展示，控制台日志保留 action 上下文但不输出邀请码、密钥或完整载荷。

作业页默认筛选“未完成”，科目使用横向滚动标签，搜索防抖 300ms。通知页按分类和标题搜索。习惯页展示目标进度和连续天数，详情页按月读取打卡并允许当天打卡。计划页按日/周/月切换并允许更新子任务状态。

## 错误处理

参数错误返回 `INVALID_ARGUMENT` 语义消息，未登录/未注册返回 `UNAUTHORIZED`，无权限返回 `FORBIDDEN`，资源不存在返回 `NOT_FOUND`，冲突返回 `CONFLICT`。云函数顶层统一捕获未知异常，服务端记录 action 与错误堆栈，客户端只收到不含敏感数据的通用信息。

## 验证

由于项目要求零依赖，纯函数测试使用 Node.js 内置 `node:test`，覆盖学期计算、日期范围、资料注册、邀请码、作业排序、权限和积分规则。所有 JavaScript 文件使用 `node --check` 做语法检查，JSON 文件使用 Node.js 解析，WXML/WXSS 做静态结构检查。OpenID 注册、家庭邀请码、云数据库权限、上传和订阅消息必须在微信开发者工具及真实云环境中完成最终联调。
