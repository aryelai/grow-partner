# AI 作业导入设计

## 状态

- 设计日期：2026-09-13
- 产品范围：已由用户确认，包含周作业登记表与普通单日截图自适应识别
- 发布边界：仅在 `codex/ai-homework-import` 本地开发、测试和提交；不部署，不修改正在审核的 `1.0.0`

## 目标

- 创建者和普通家庭成员可从作业列表进入“AI 导入作业”。
- 一次选择 1–3 张 QQ 作业截图，识别成多条可编辑、可勾选的作业草稿。
- 草稿字段包括学期、科目、主题、内容、补充要求和截止时间。
- 用户明确确认后才调用现有 `homework.create` 保存；识别结果绝不自动入库。
- 截图只用于本次识别，识别结束后由服务端删除，不成为作业附件。
- 默认智能判断截图版式：周表只导入最右侧存在有效作业的最新列，单日清单、聊天记录截图和普通单日截图导入全部作业。

## 非目标

- 本轮不识别语音、文档或聊天记录导出文件。
- 本轮不自动判断作业已完成、重要程度或提醒策略。
- 本轮不部署云函数、创建集合、修改云存储规则或更改线上数据。
- 本轮不接入第三方 API Key，不在客户端暴露模型、提示词或密钥。

## 用户流程

1. 具有新增作业权限的用户在作业列表点击“AI 导入”。
2. 用户保留默认“智能判断”，或手动选择星期一至星期五/周末、整周；页面选择 1–3 张压缩图片，客户端校验格式和单张大小。
3. 客户端向 `ai.createImportJob` 提交识别范围，并申请与当前身份绑定的随机临时路径和上传凭据。
4. 客户端只向凭据指定路径上传，然后调用 `ai.analyzeImportJob`。
5. 服务端重新校验身份、家庭、任务所有权、过期时间和文件清单，读取图片并调用 CloudBase 托管多模态模型。
6. 服务端校验并规范化模型 JSON，返回最多 60 条草稿、版式/范围/周次摘要和警告，同时在 `finally` 中删除临时图片。
7. 客户端只调用一次作业列表接口，核对当前学期最近 50 条作业，精确匹配科目、主题、内容和补充要求；可能重复项默认取消勾选但允许用户重新勾选，检查失败不阻断识别和保存。
8. 用户编辑、取消勾选或确认保存；客户端为每条草稿携带由本次任务 ID 和草稿序号生成的稳定 `requestId`，逐条调用 `homework.create`。服务端以当前 OpenID、家庭和 `requestId` 实现幂等创建，成功项立即标记为已保存，失败项留在页面重试。

## 安全与隐私

- 只允许 `creator`、`member`；`child` 在客户端和云函数均拒绝。
- 不信任客户端传入的 OpenID、`familyId`、云文件 ID、上传路径或科目列表。
- 识别范围只接受固定白名单；在创建任务时绑定到任务文档，分析接口忽略客户端再次传入的范围，兼容旧任务缺失范围时按 `auto` 处理。
- 上传路径由服务端随机生成，并在 `ai_import_jobs` 中绑定 OpenID、家庭、文件 ID、格式和过期时间。
- 保持云存储客户端全局 `write:false`；使用服务端签发的精确对象上传元数据，客户端不调用 `wx.cloud.uploadFile`。
- 只接受 JPEG、PNG，单张最多 4 MB，一次最多 3 张；服务端下载后再次核对真实字节数和文件魔数。
- AI 模型名和每日任务上限来自 `AI_MODEL`、`AI_DAILY_LIMIT`；任一缺失或非法时功能关闭。
- 每日额度使用北京时间和服务端确定性限流文档，不接受客户端日期。
- 日志只记录 action、任务 ID、阶段和错误摘要，不记录 OpenID、截图、OCR 正文、上传凭据或模型完整响应。
- 任务文档不保存识别正文；清理失败只记录 `cleanupRequired` 供后续运维处理。

## 识别规则

- 模型输出必须是 JSON；服务端容忍 Markdown 代码块，但拒绝无法解析或结构不符的内容。
- `auto` 下，周表只提取最右侧存在有效作业的列；单日清单、聊天记录或普通单日截图提取全部作业。
- 手动星期只筛选周表对应列，输入不是周表时仍提取全部；`full_week` 提取周表所有非空列。
- 多张截图中的连续、跨图和重复内容合并去重；星期列表示登记范围，不得推断为截止日期。
- 模型返回白名单 `sourceType`、周表自动模式的白名单 `detectedScope`、`weekLabel`、`truncated` 和逐条 `uncertainFields`；页面使用的中文范围摘要由服务端按版式和任务绑定范围派生，不接受模型自由文本，页面将不确定字段标黄。
- 只有文本明确表达某个日期或时间是截止、提交或完成时间时才填写截止时间；标题日期、作业日期、周次、星期和发布日期均不得当作截止时间。
- 相对日期以服务端提供的北京时间为锚点。
- 科目只接受家庭当前科目列表中的精确值；无法匹配时科目留空并要求用户选择。
- 主题、正文、补充要求分别限制为现有作业接口允许的长度。
- 模型输出最多接受 60 条，超出部分或模型声明 `truncated` 时提示用户按星期分批导入。服务端还检查 CloudBase `rawResponses` 中明确的 `choices[].finish_reason` 和完成 token 数，发现长度截断时返回专用提示；该值是服务端接收上限，不保证模型单次一定输出 60 条。

## 云端接口

### `ai.getStatus`

返回 `enabled`、`canImport`、`maxImages`、`maxImageBytes` 和不可用原因；不返回模型名、每日额度、OpenID 或配置细节。

### `ai.createImportJob`

输入文件元信息数组和 `importScope`；服务端按白名单校验权限、范围与当日额度，返回 `jobId`、`expiresAt` 和逐文件上传凭据。上传凭据仅用于服务端生成的随机路径。

### `ai.analyzeImportJob`

只接收 `jobId`。任务必须属于当前用户和家庭且处于可处理状态；识别范围只从任务读取；成功返回 `drafts`、`warnings`、`summary`，无论成功失败都尝试删除临时图片。

### `ai.cancelImportJob`

只接收 `jobId`。用于凭据签发后、进入识别前的客户端上传失败；服务端重新校验当前用户、家庭和任务状态，删除已上传或可能已上传的任务文件并把任务标记为已取消。取消失败不覆盖客户端原始错误。

## 数据模型

新增客户端不可读写集合 `ai_import_jobs`，同时存放两类文档：

- `job`：所有者哈希、`familyId`、`importScope`、文件清单、状态、过期时间、创建/更新时间、清理状态；不保存识别正文。
- `rate_limit`：OpenID 哈希、北京时间日期、计数和更新时间；文档 ID 为服务端哈希。

## 失败与恢复

- 选图、凭据申请、上传、识别、解析和保存分别显示明确错误，不静默吞错。
- 上传失败时客户端尽力调用 `cancelImportJob`，识别阶段由服务端 `finally` 清理；两者都不自动保存，用户可重新发起一次导入。
- 多条保存过程中若部分失败，已成功项不可再次提交，未成功项保留并可重试；云端已写入但响应丢失时，相同 `requestId` 返回原作业，不重复创建或覆盖内容。
- 页面通过 `homework.list` 的 `created_at_desc` 白名单排序单次读取当前学期最近 50 条，并同时检查本批草稿中的完全重复项；检查失败、较早作业未覆盖或用户确认并重新勾选可能重复项时均不硬拦截，由用户完成最终判断。
- 部署前若需回退，只需不部署此分支；部署后可清空 `AI_MODEL` 或 `AI_DAILY_LIMIT` 立即关闭入口和新任务。
