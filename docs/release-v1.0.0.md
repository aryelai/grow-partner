# v1.0.0 家庭内测正式版发布清单

## 发布定位

`v1.0.0` 仅面向持有现有家庭邀请码的受信任成员收集真实使用反馈，不作为公开扩量版本。新用户必须先用邀请码完成资料注册，再在加入页重复输入邀请码并等待家庭创建者批准；家庭内测期间禁止新建家庭和新增附件。小程序代码上传、微信审核提交和正式发布都是独立的外部操作，必须在执行前获得用户明确确认。

## 已完成

- 小程序主体审核、认证和 ICP 备案已由用户完成。
- 九个云函数已部署到唯一 CloudBase 开发环境，订阅集合、必需索引、客户端拒绝规则和定时触发器已配置。
- 真机已完成一次订阅授权、自然定时发送和实际收件，未发现重复发送。
- 最新本地代码已修复无订阅次数任务固定占用扫描窗口的问题。
- 最新本地代码已锁定订阅消息携带通知 ID 并进入只读通知详情页的路径。
- 家庭邀请码注册门禁、每天 20 次防枚举和新建家庭禁用逻辑已部署到开发环境；客户端新增附件入口已移除并包含在已上传的 `1.0.0` 中，仍待真机验证。
- 本地核心测试和静态项目校验通过，代码提交目前仅存在本地 Git 分支，未推送。
- 2026-09-12 17:00 已通过微信开发者工具上传小程序代码包 `1.0.0`，项目备注为“首版家庭内测：作业、通知、习惯、计划、家庭协作与订阅提醒”；工具明确显示“代码上传成功”。

- [x] 部署 `login`、`family` 并同时配置 `REGISTRATION_MODE=family_invite`。2026-09-12 已核对 `$LATEST` 更新时间分别为 15:39:11、15:39:41，两个函数的环境变量值均为 `family_invite`。
- [ ] 使用真机确认缺失或非法配置默认关闭新注册；验证完成前不修改已核对的开发环境配置。
- [ ] 把云存储客户端规则设置为原上传者可读、`write: false`，确认历史附件仍可读取且任何客户端新增上传都会被拒绝。
  - 2026-09-12 用户将原环境升级为个人版后，已重新保存自定义规则；控制台显示“权限变更完成”，重新打开编辑器核对内容与清单一致。仍待用历史附件读取和一次客户端上传拒绝完成行为验证。
- [ ] 使用另一微信账号验证：无邀请码和错误邀请码无法注册；有效邀请码可以注册并申请加入；创建者批准后可以进入家庭；新建家庭入口和全部新增附件入口不可用。
- [ ] 用户确认并接受提醒队列的已知容量限制：按每轮最多 50 条、每 30 分钟一轮计算，同一两小时窗口的理论上限约为 200 条更早的无额度任务，实际容量还可能受 3 秒云函数超时影响而更低。
- [x] 获得用户授权后，通过微信开发者工具上传最新小程序代码，版本号使用 `1.0.0`。
- [ ] 保持 `MINIPROGRAM_STATE=developer`，使用上传后的最新开发版冷启动，重新发送一条真实订阅消息，确认点击消息直接进入对应的只读通知详情页，且标题、来源和内容正确。
- [ ] 若需要体验版回归，先暂停 `reminderTimer`，把 `MINIPROGRAM_STATE` 临时切为 `trial`，完成测试后恢复为 `developer` 并核对配置，再恢复触发器，避免开发版和体验版链接混发。
- [ ] 核对隐私保护指引覆盖微信用户信息、孩子姓名、生日、班级等未成年人信息、家庭资料、作业与通知附件、云存储用途、监护人同意、注销或删除方式以及有效联系方式。
- [ ] 核对服务类目、体验账号或审核说明能够覆盖注册、加入家庭、作业、通知、计划和习惯等主要审核路径。
- [ ] 提交微信代码审核，并保存审核版本和结果。
