# v1.0.0 家庭内测正式版发布清单

## 发布定位

`v1.0.0` 的业务目标是仅面向受信任的家庭成员收集真实使用反馈，不作为公开扩量版本。但当前代码没有服务端内测准入控制，正式发布后任意微信用户仍可注册、创建或申请加入家庭，因此不能只靠产品定位限制用户范围。小程序代码上传、微信审核提交和正式发布都是独立的外部操作，必须在执行前获得用户明确确认。

## 已完成

- 小程序主体审核、认证和 ICP 备案已由用户完成。
- 九个云函数已部署到唯一 CloudBase 开发环境，订阅集合、必需索引、客户端拒绝规则和定时触发器已配置。
- 真机已完成一次订阅授权、自然定时发送和实际收件，未发现重复发送。
- 最新本地代码已修复无订阅次数任务固定占用扫描窗口的问题。
- 最新本地代码已锁定订阅消息携带通知 ID 并进入只读通知详情页的路径。
- 本地核心测试和静态项目校验通过，代码提交目前仅存在本地 Git 分支，未推送。

## 发布前必须完成

- [ ] 在正式发布前完成一项可验证的准入方案：实现服务端家庭内测白名单或邀请码门禁；或者按公开可注册产品的标准完成上传权限和内容安全。未经选择并完成其中一项，不提交正式版审核。
- [ ] 若选择受控家庭内测，服务端必须默认拒绝未授权微信用户注册、创建家庭和申请加入家庭；准入凭据不得硬编码在小程序代码中。
- [ ] 若选择公开可注册，必须把附件上传改为服务端可校验的授权流程，限制所属用户或家庭、路径、文件类型、大小和额度，并接入文本与媒体内容安全检查。当前云存储规则无法读取 `users.role`，仅在客户端隐藏孩子上传入口不能作为发布保障。
- [ ] 用户确认并接受提醒队列的已知容量限制：按每轮最多 50 条、每 30 分钟一轮计算，同一两小时窗口的理论上限约为 200 条更早的无额度任务，实际容量还可能受 3 秒云函数超时影响而更低。
- [ ] 获得用户授权后，通过微信开发者工具上传最新小程序代码，版本号使用 `1.0.0`。
- [ ] 保持 `MINIPROGRAM_STATE=developer`，使用上传后的最新开发版冷启动，重新发送一条真实订阅消息，确认点击消息直接进入对应的只读通知详情页，且标题、来源和内容正确。
- [ ] 若需要体验版回归，先暂停 `reminderTimer`，把 `MINIPROGRAM_STATE` 临时切为 `trial`，完成测试后恢复为 `developer` 并核对配置，再恢复触发器，避免开发版和体验版链接混发。
- [ ] 核对隐私保护指引覆盖微信用户信息、孩子姓名、生日、班级等未成年人信息、家庭资料、作业与通知附件、云存储用途、监护人同意、注销或删除方式以及有效联系方式。
- [ ] 核对服务类目、体验账号或审核说明能够覆盖注册、加入家庭、作业、通知、计划和习惯等主要审核路径。
- [ ] 提交微信代码审核，并保存审核版本和结果。
- [ ] 审核通过并获得用户最终发布确认后，先暂停 `reminderTimer`，再发布正式版。
- [ ] 正式版发布成功后，把 `reminder` 的 `MINIPROGRAM_STATE` 从 `developer` 改为 `formal`，重新核对最小 OpenAPI 权限和 Cron，再恢复 `reminderTimer`。
- [ ] 正式环境再发送一条真实提醒，验证消息点击、只读详情、字段显示和不重复发送。

## 当前不得宣称完成的事项

- 最新小程序代码尚未上传，旧开发版消息落地异常尚未完成真机回归。
- 微信代码审核尚未提交，正式版尚未发布。
- 服务端家庭内测准入尚未实现；当前正式发布会允许任意微信用户注册。
- 云存储角色级防绕过、内容安全、备份与恢复尚未完成公开发布级验收。
- `devres.project.yaml` 仍声明没有正式发布流程；在用户确认本清单前不修改该项目事实。
