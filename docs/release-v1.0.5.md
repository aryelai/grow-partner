## 本版范围

- 作业支持“指定日期/全部待办”，逾期任务优先展示，并增加需要帮助、待家长检查、待订正和已订正等可选学习状态。
- 通知支持内部要求清单、逐项完成、按处理优先级排序，以及智能导入后的单条整合或多条批量保存。
- 成长页增加基于原始作业、通知要求、计划和习惯数据的客观本周复盘，不做排名和主观评价。
- 孩子账号可创建和维护自己创建且由自己执行的计划，不能修改成人计划。
- 课程表支持指定日期的临时调课和停课，不改写固定周课表。
- 作业、通知和课程表识别页保留本地原图供放大核对；家庭可配置教材简称和校内常用词作为只读识别提示。
- “我的”增加家庭数据导出、普通成员退出家庭和删除边界说明。
- 用户可见的图片识别文案统一使用“智能导入”“智能识别”和“图片识别服务”，不展示内部模型术语。
