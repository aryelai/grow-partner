# 成长搭档

成长搭档是一款面向初中生家庭的微信小程序，用于集中管理作业、学校通知、习惯打卡和日/周/月计划。项目采用微信小程序原生框架与微信云开发。

## 当前实现

- Phase 0：OpenID 注册、孩子档案、家庭创建、邀请码查找、加入申请审批、成员管理。
- Phase 1：作业 CRUD、横向科目筛选、默认未完成筛选、300ms 搜索防抖、重要/限时状态、图片/视频/链接、完成切换。
- Phase 2：通知 CRUD 与提醒字段、日/周/月计划、计划子任务执行、习惯分类、日历打卡、连续天数和积分。
- Phase 3：家庭设置、当前学期、自定义科目、提醒偏好，以及通知的一次性订阅授权、30 分钟调度、防重复发送和只读消息落地页。AI 仍为安全占位。

## 本地检查

项目不需要安装根目录依赖。使用 Node.js 运行纯逻辑测试和静态检查：

```bash
node --test tests/*.test.js
node scripts/validate-project.js
```

## 导入与部署

1. 用微信开发者工具导入本目录。
2. 在 `project.config.json` 中填入真实 AppID，并开通云开发环境。
3. 按 [云开发部署与数据设计](cloudfunctions/README.md) 创建集合与索引。
4. 在开发者工具中逐个上传九个云函数，选择由云端安装官方 `wx-server-sdk` 依赖。
5. 使用开发版真机完成 OpenID 注册、家庭邀请码、上传、云数据库权限和页面流程联调。

## 配置说明

- `project.config.json` 已配置当前小程序 AppID；AppID 不是密钥，但不得提交 AppSecret 等敏感配置。
- 默认当前学期为 `2026下`，家庭创建者可在设置页切换。
- 生产数据不得通过客户端直连集合；所有业务访问必须经过对应云函数。
