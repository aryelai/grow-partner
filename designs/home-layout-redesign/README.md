# 成长搭档首页布局重设计

用户已确认版：[`layout-v3.html`](./layout-v3.html)，保留上一版 [`index.html`](./index.html) 供对照。

## 确认与待实施项

- 用户于 2026-09-15 明确认可当前原型的信息架构和布局，作为后续原生小程序实施的设计基线。
- 通知卡片“标为完成／撤销完成”入口尚未在原型实现，后续落地按与作业一致的直接可见按钮补齐；完成表示事项已办妥，不表示已阅读，也不等同于提醒已发送。
- 本次确认只记录设计认可，不视为提交、推送、部署、上传或发布授权；原生小程序实施与验收仍待开始。

## 信息架构

- 底部导航：`首页 / 作业 / 通知 / 成长 / 我的`
- 成长：顶部“习惯打卡 / 计划安排”同级页签，各自保留独立新增入口
- 计划：首页“今日计划”直达今天的日计划，“我的”保留完整管理入口；成长页支持日、周、月计划
- 课程表：首页按上午、下午完整展开今日课程；完整管理入口位于“我的”及作业页“更多”
- 设置：更名为“我的”，按“学习管理”和“服务与偏好”重新分组

## 首页层级

1. 当前孩子、日期与学期
2. 今日待办概览
3. 今日全部课程
4. 待完成作业
5. 重要通知
6. 今日计划与习惯打卡
7. AI 导入等快捷处理

## 交互说明

- 点击底部导航可查看五个一级页面的布局关系。
- 点击首页作业圆圈可切换完成状态。
- 作业页保留当前学期、科目和状态筛选。卡片顶部只显示大字号科目及日期值，不重复字段名称；主题完整显示。
- 作业卡片提供直接可见的“标为完成”，完成后进入“已完成”，提供即时撤销；已完成卡片也可恢复为未完成。状态与首页作业及待完成数量同步，不依赖左滑发现操作。
- 作业、通知页的 AI 导入、新增及“更多”固定在列表顶部，滚动到底仍然可用；课程表与提醒设置分别收进对应页面“更多”。
- 今日课程采用上午、下午两列，上午 4 节、下午 4 节共 8 节全部展开；缩减行高和留白，保留科目、节次与时间，不用横滑或折叠寻找其他课程。课程安排与时间仍为示例，生产接入时按实际课程展示。
- 通知页支持“处理状态 + 分类”组合筛选，并展示无匹配结果提示。提醒时间、截止时间、事项时间分别标识，不将提醒发送状态当作处理完成状态。
- 成长页可按行为、生活、学习分类筛选习惯；打卡按钮同步更新当天完成数量。
- 新增习惯表单包含名称、分类、每日目标和目标天数；保存后进入对应分类。
- 新增计划表单包含主题、周期、日期及逐行子任务；保存后进入对应日期周期，可以逐项勾选并更新完成率。
- 计划日期导航按日、周、月移动；没有计划的周期展示空状态。
- AI 导入等未接入的业务入口只展示演示提示，不执行真实识别。
- 表单支持取消、关闭和空白校验；输入控件至少 48px 高，筛选及新增按钮至少 44px 高。

该原型仅用于确认信息架构与视觉层级，不连接云函数或真实数据。示例日期固定为 2026-09-15，课程及高亮节次为演示数据，不代表真实当前课程；新增、打卡及作业完成数据仅保存在当前页面内存中，刷新后重置。

## 上线边界

通知处理状态、事项时间、截止时间目前仅在原型中演示，尚未扩展生产云函数字段，也未部署或上传微信。原生小程序中现有的习惯与计划页面不会因本原型修改而改变。
